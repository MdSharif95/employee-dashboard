# Employee Dashboard

A responsive employee dashboard interface focused on:
- employee overview KPIs
- productivity and performance analysis
- live field map tracking
- recent activity updates

## Run locally

Open `index.html` directly in your browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — dashboard structure
- `styles.css` — visual design and responsive layout
- `script.js` — example data rendering for metrics, charts, and activity updates

## Notes

This is a modern front-end mock dashboard meant for UI layout and analytics presentation, with map tracking visuals and performance summaries.
